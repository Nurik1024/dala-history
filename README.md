# DALA — Қазақстан тарихы

Қазақстан тарихы туралы қазақ тіліндегі интерактивті сайт.

- 1822–1824 жылдардағы әкімшілік реформалар
- 1867–1868 жылдардағы әкімшілік реформалар
- Бөкей Ордасы

Барлық мәтін, стиль, JavaScript және төрт иллюстрация `index.html` файлына енгізілген. Қосымша тәуелділіктер мен құрастыру қадамы қажет емес.

## Жергілікті ашу

`index.html` файлын заманауи браузерде ашыңыз. Интернет тек сыртқы дереккөз сілтемелеріне өту үшін қажет.

## GitHub Pages

Repository **Settings → Pages → Build and deployment** бөлімінде **Deploy from a branch**, **main**, **/ (root)** таңдаңыз.

## Материалдар

Тарихи мәтіндердің бастапқы материалы мен дереккөздері сайттың ішінде көрсетілген. Иллюстрациялар ImageGen көмегімен жасалған көркем бейнелер; мұрағаттық фотосуреттер емес.
